# Vignette (크롬 확장)

유니챗 전용 유저스크립트(Univers Scene Painter 6.4.11)를 여러 플랫폼에서 쓸 수 있는 크롬 확장으로 옮긴 버전입니다.

   설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `scene-painter-ext` 폴더 선택
4. 이미 열려 있던 채팅 탭은 새로고침

> 유저스크립트(탬퍼몽키)와 같이 켜 두면 버튼이 두 번 붙습니다. 확장을 쓸 땐 유저스크립트를 꺼 주세요.

   사용

- **메뉴 열기 방식**은 고를 수 있습니다 (툴바 확장 아이콘 팝업 아래쪽, 또는 관리 페이지 › 환경설정)
  - **플로팅 버튼** (기본) — 채팅방 오른쪽 아래 🎨 버튼. 끌어서 옮길 수 있고 위치는 사이트마다 기억합니다.
  - **확장 패널** — 화면에 아무것도 띄우지 않고, 툴바의 확장 아이콘(단축키 **Alt+Shift+S**)에서 같은 메뉴를 씁니다.
  - **둘 다**
- 메뉴 구성:
  - 켜기 · 퀵 패널 · 마지막 답변 삽화 · 스피드 생성 · 갤러리 · 설정 (기존과 같음)
  - **본문 위치 지정** — AI 답변 글을 클릭. 안내창에 예시 그림과 ✔/✘ 목록이 나오고, 마우스를 올리면 실제로 잡힐 범위(자동 보정됨)와 "지금 확정하면 N곳"이 미리 보입니다. 휠이나 ↑↓로 범위를 넓히고 좁힐 수 있습니다.
  - **하단 위치 지정** — 답변 아래 버튼 줄(복사/재생성 등)을 클릭. 삽화 버튼이 여기에 붙습니다. 지정하지 않으면 본문 바로 아래에 줄을 만들어 붙입니다.
  - **내 메시지 제외 지정** — 내 메시지까지 버튼이 붙는 사이트에서만 쓰면 됩니다.
  - **위치 확인 · 자동 진단** — 잡힌 본문(주황) · 하단(파랑) · 제외된 내 메시지(회색 점선)를 화면에 표시하고, 문제가 있으면 원인과 [고치기] 버튼을 보여 줍니다. 위치를 지정하고 나면 자동으로 열립니다.
  - **위치 초기화** · **관리 페이지 열기**

    자가 진단 · 자동 복구 (규칙표)

API를 쓰지 않고 "이런 경우엔 이렇게" 규칙으로 고칩니다. 자동으로 고치면 알림에 **되돌리기**가 함께 나옵니다. (관리 페이지 › 환경설정에서 끌 수 있음)

| 상황 | 처리 |
|---|---|
| 셀렉터 문법이 깨짐 | 기본값으로 되돌리기 / 비우기 |
| 메시지 묶음 표시 이름이 바뀜 (예: `data-message-id` → `data-msg-key`) | 새 속성을 찾아 묶음 셀렉터 고치기 |
| 본문 클래스가 조금 바뀜 | AI 답변 표시(역할 속성)는 지킨 채 셀렉터를 느슨하게 |
| 지금 설정은 안 되는데 기본값/예전 설정은 됨 | 기본값 · 마지막으로 잘 되던 설정으로 |
| 본문 글이 너무 짧음 (이름표를 고름) | 한 단계 넓히기 |
| 본문 안에 본문이 겹침 | 바깥 것만 쓰기 |
| 내 메시지가 섞임 | `user` 같은 역할 표시를 찾아 제외 |
| 하단 줄을 못 찾음 / 본문까지 품음 | 하단 비우기(본문 아래 자동 줄) |
| 삽화 버튼이 두 번 붙음 | 버튼 다시 붙이기 |
| 채팅방 주소 규칙이 안 맞음 | 주소 자동 판별로 |
- 툴바의 확장 아이콘(팝업)에서 사이트를 켜고 끄거나, 목록에 없는 사이트를 **이 사이트에서 사용하기**로 추가할 수 있습니다.

   기본으로 들어 있는 사이트

| 사이트 | 상태 |
|---|---|
| 유니챗 | 기존 유저스크립트 판별 로직 그대로 (자동 인식) |
| 엘린 · 로판 AI · 리루 · 우마이 | 2026-10 DOM으로 프리셋 검증 완료 |
| 케이브덕 | 첫 인사말 기준 프리셋 (내 메시지 구조는 미확인 → 필요하면 "내 메시지 제외 지정") |
| 티팟 | 프리셋 없음 → 🎨 메뉴에서 본문/하단 위치 지정 |

   저장 구조 (플랫폼별 · 채팅별)

- 모든 기록은 사이트가 아니라 **확장 저장소**에 들어갑니다. 사이트 쿠키/저장소를 지워도 남습니다.
- 방 키 = `<플랫폼>__<채팅ID>` (예: `elyn__66b310b1-…`). 방별 설정 · 장면 기록 · 이미지가 이 키로 나뉩니다.
- 이미지는 확장 IndexedDB, 설정/기록은 `chrome.storage.local`(용량 제한 없음)에 저장됩니다.

   관리 페이지

확장 아이콘 → **관리 페이지 열기** (또는 🎨 메뉴 › 관리 페이지 열기, 확장 옵션)

- **보관함** — 삽화를 만든 채팅만 모읍니다(들어가 보기만 한 채팅은 쌓이지 않음). 설정만 있고 삽화 없는 채팅은 "보기/정리"로 따로 관리. 플랫폼 묶음은 접을 수 있고 24개씩 나눠 보입니다. 플랫폼별로 묶인 채팅 목록 → 채팅을 누르면 그 채팅의 삽화 · 기록 · 이름 바꾸기 · 이미지 ZIP · 이 채팅 백업 · 삭제
- **전체 갤러리** — 모든 플랫폼의 삽화, 플랫폼 필터, 프롬프트 보기, 저장/삭제
- **사이트 설정** — 사이트별 켜기/끄기, 셀렉터 직접 수정, 사이트 추가/삭제, 기본값 복원
- **백업 · 복원** — **ZIP 전체 백업**: 데이터 + 모든 이미지를 `images/플랫폼/채팅/날짜.png` 폴더로 정리해서 ZIP 하나로. 그 ZIP 그대로 복원 가능. 범위(전체/플랫폼) · 형식(ZIP/.cspbak) · API 키 포함 여부 선택(기본 제외). 복원은 합치기/덮어쓰기
- **환경설정** — 메뉴 열기 방식, 테마(베이지/다크/라이트/시스템 따라가기), 위치 자동 복구, 고아 이미지 정리, 전체 삭제
- 사이드바의 저장 공간은 이미지 + 설정·기록을 합친 실제 사용량입니다

   유저스크립트 기록 옮기기

유니챗 채팅방에서 🎨 메뉴 › **유저스크립트 기록 가져오기**. 유저스크립트가 univers.chat 사이트 저장소에 남긴 설정 · 방별 설정 · 장면 기록 · 이미지를 확장으로 복사합니다(원본은 지우지 않음). 가져온 뒤 새로고침하세요.

   파일

```
manifest.json          MV3 설정 (크롬 기준 — 파이어폭스용은 빌드할 때 바꿔 끼움)
scripts/build.mjs      배포용 zip 만들기 (크롬 / 파이어폭스)
background.js          사이트 주입 · API 요청 대리(CORS) · 이미지 저장소
content/loader.js      모든 페이지에 붙는 작은 스크립트 (켜진 사이트만 본체 주입)
content/bootstrap.js   저장소/네트워크 연결, 위치 지정 피커
content/core.js        기존 유저스크립트 본체 + 범용 DOM 어댑터 + 플로팅 버튼
shared/platforms.js    사이트 프리셋 · 채팅 ID 규칙
shared/imagedb.js      이미지 IndexedDB
manager/               관리 페이지
popup/                 툴바 팝업
```

   파이어폭스

```
node scripts/build.mjs            # dist/vignette-chrome-<버전>.zip, dist/vignette-firefox-<버전>.zip
node scripts/build.mjs firefox    # 파이어폭스만
```

- 코드는 같고 manifest만 다르다: `background.service_worker` → `background.scripts`, `browser_specific_settings.gecko` 추가 (데스크톱 140+, 안드로이드 142+)
- 테스트: `about:debugging` › 이 Firefox › 임시 부가 기능 로드 › `dist/firefox/manifest.json`
- 배포: addons.mozilla.org에 `dist/vignette-firefox-*.zip` 업로드
- 폴더 저장(`showDirectoryPicker`)은 파이어폭스에 없어서 안내 메시지만 뜬다
